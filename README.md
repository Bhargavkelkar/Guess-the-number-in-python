# Guess the Number Game 🎲

A fun and interactive Command Line Interface (CLI) Python game built as part of the **Hack Club Stardance** program.

## 🌟 Features
- **Dynamic Feedback:** Guides the player with "Too high!" or "Too low!" hints.
- **Input Validation:** Prevents crashes by verifying user inputs are valid positive numbers.
- **Attempt Tracker:** Keeps count of how many guesses it takes to land on the correct answer.
- **Secret Reveal:** Confirms the secret number upon winning.

## 🚀 How to Run
Make sure you have Python installed, then run the following command in your terminal:

```bash
py "guess the number.py"
